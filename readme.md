Проект по математическому моделированию (Вариант 23)

Это интерактивное веб-приложение на базе Python и Streamlit, предназначенное для расчета параметров линейной регрессии методом наименьших квадратов (МНК) и прогнозирования вероятностей по нормальному закону распределения.

🚀 Как запустить приложение

Для запуска приложения на твоем компьютере должен быть установлен Python (версии 3.9 и выше).

1. Установка необходимых библиотек

Открой терминал (командную строку) и выполни следующую команду для установки всех зависимостей:

pip install streamlit numpy scipy matplotlib


2. Запуск приложения

Перейди в папку с файлом app.py и запусти сервер Streamlit:

streamlit run app.py


После этого в твоем браузере автоматически откроется вкладка с работающим приложением.

🛠️ Описание кода и технологий

Приложение построено по принципу «одной страницы» для максимального удобства презентации.

1. Используемые библиотеки

Streamlit: Позволяет превратить Python-скрипт в полноценный сайт. Все элементы интерфейса (кнопки, таблицы, математические формулы) созданы с её помощью.

NumPy: Используется для высокоскоростных расчетов. Мы работаем с данными как с массивами, что позволяет мгновенно считать суммы $\sum x$, $\sum y$ и выполнять матричные операции.

SciPy (stats.norm): Нам нужна для вычисления интегральной функции Лапласа. Она заменяет бумажные таблицы из учебников, обеспечивая высокую точность.

Matplotlib: Генерирует визуализацию данных — строит корреляционное поле (точки) и линию тренда (красная прямая).

2. Математический блок

В коде реализовано три независимых алгоритма решения системы уравнений:

Метод Гаусса: Пошаговое исключение переменных.

Метод Крамера: Решение через определители (детерминанты).

Матричный метод: Нахождение вектора параметров через обратную матрицу $(X^T X)^{-1}$.

3. Вероятностный блок

Программа рассчитывает вероятности событий на основе нормального распределения.

Важный нюанс: Для того чтобы результаты в программе совпадали с результатами в презентации (где значения брались из таблиц), в коде реализовано принудительное округление аргумента $z$ до 3 знаков. Это имитирует ручной поиск по таблице Лапласа.

4. Дизайн (Neo-brutalism)

Интерфейс стилизован под современный тренд "Необрутализм":

Использование жирных черных обводок и теней без размытия.

Контрастные акцентные цвета (ярко-красный на светлом градиентном фоне).

Крупная типографика для акцентирования внимания на итоговых цифрах.
